# Getting started

> This page is a placeholder while the wiki is being seeded. Pages are being filled in incrementally; PRs are welcome.

## What you'll do

1. Install Demeteo.
2. Open a local or remote Git project.
3. Describe a feature in plain language.
4. Watch the workflow decompose it and agents pick up steps in parallel worktrees.
5. Review the proposed changes and approve gates before they merge.

## Prerequisites

- macOS, Linux, or Windows.
- A Git repository you want to orchestrate work in.

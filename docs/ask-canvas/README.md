# Ask Canvas Mockup

This directory preserves the portable Ask Canvas design mockup and its source fragments.

Open the files in `probe/` in a browser. They are self-contained artboards with
the required styling inlined.

| Artboard | Shows |
| --- | --- |
| [Empty](probe/Empty.html) | A new Ask thread. |
| [Main](probe/Main.html) | An answered Ask thread with a canvas drawn. |
| [Streaming](probe/Streaming.html) | An Ask thread answering while researching the web. |
| [CanvasFocus](probe/CanvasFocus.html) | A focused canvas with the node inspector open. |
| [WebAccess](probe/WebAccess.html) | The thread settings web-access control. |
| [Nodes](probe/Nodes.html) | The canvas node vocabulary sheet. |

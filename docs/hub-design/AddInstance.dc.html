What changes on the runner

It opens one outbound wss connection to the Hub. It still listens on no port. The Hub becomes one more client of the runner, with its own client id — it sees only runs it started, like any desktop. Its refresh token lives in the runner's credential store, bound to a device key generated on the host. Git credentials are not part of pairing. They still arrive per run from a desktop's keyring, and a run parks as Needs credentials until one does.
